# 👁️ Eyekon – Digital Eye Care System

**Eyekon** is an AI-powered digital eye care system that monitors user fatigue, stress, and focus in real-time, while promoting healthier screen usage.  
Built with **Python** and **computer vision**, Eyekon uses facial and eye tracking to provide actionable feedback and ergonomic suggestions.

---

## 🚀 Features

- **Real-Time Eye Tracking** – Detects blinks, gaze direction, and focus duration using OpenCV and dlib.
- **Fatigue Detection** – Calculates a scientifically backed fatigue score.
- **Stress Detection** – Analyzes micro-expressions to estimate stress levels.
- **Screen Automation** – Adjusts brightness and color temperature dynamically.
- **Workspace Optimization** – Recommends ergonomic improvements for better posture.
- **Break Reminders** – Sends proactive audio alerts to prevent eye strain.

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Libraries:** OpenCV, dlib, NumPy  
- **Modules:** Modular, event-driven architecture  
- **Alerts:** Audio prompts for user action
